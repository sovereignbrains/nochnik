# Ночник

Тёплый свет на экран, пока запущен `Night.exe`. Цвет зафиксирован. Крутится только тусклость.

Подсветку монитора не трогает, права администратора не нужны. На выходе картинка становится обычной.

Полоса до риски — тот же тёплый свет, слабее или как сейчас. Правее риски драйвер не принимает канал ниже 0.50, поэтому дальше экран прикрывает прозрачная плёнка. Клики сквозь неё проходят.

Закрытие окна прячет программу в трей. Второй запуск открывает окно, а не выключает свет.

Сборка:

```
powershell -ExecutionPolicy Bypass -File build.ps1
```
